# Argentum 3.0 — гибридное ядро

Статус: согласовано 2026-10-29, ветка `feature/hybrid-core`. Документ живой: решения меняются только по согласованию.

## Цель

Моды **Fabric, Forge и NeoForge в одной игре одновременно**. Первая версия игры — **Minecraft 1.21.1**, следом 1.20.1;
версия игры — отдельный слой ядра. Сроки не давят: делаем аккуратно.

Продукт: нынешний Argentum (на основе Fabric Loader) становится **Argentum Legacy**, гибрид выходит как **Argentum 3.0**,
потом остаётся только 3.0.

## Рубежи

1. **Контрольный набор**: Create и JEI (NeoForge), Sodium и Mod Menu (Fabric), один мод Forge 1.21.1 — вместе в одном мире
   без падений.
2. **Настоящая сборка**: NeoForge-сборка игрока (инстанс «Game Politic Client») плюс несколько Fabric-модов.
3. **Топ Modrinth**: 20–30 самых скачиваемых модов 1.21.1 всех трёх видов.

## Путь: от гибрида к своему ядру

Начинаем на готовых открытых частях и заменяем их своими по этапам.

| Этап | Наше | Ещё чужое | Переход, когда |
|---|---|---|---|
| 1. Гибрид | поиск и проверка модов всех видов, перевод имён, слои Fabric и Forge, все функции Argentum | запуск игры, правки кода игры, API NeoForge | — |
| 2. Свой запуск | запуск и цепочка правки классов; NeoForge работает внутри ядра | правки кода игры, API NeoForge | рубеж 1 стабилен |
| 3. Свои правки игры | изменения Minecraft, нужные модам | реализация API NeoForge | рубеж 2 пройден |
| 4. Своё ядро | свой API для модов всех трёх видов | — | рубеж 3 пройден |

Чужой код: NeoForge (LGPL-2.1), Sinytra Connector (MIT), Forgified Fabric API (Apache-2.0). Их лицензии прикладываются,
изменения LGPL-части публикуются; наш код — ARR.

## Этап 1: из чего состоит

1. **Argentum Core** (`argentum-core`) — общая часть без привязки к загрузчику: Modrinth и каталог (без экранов), снимки и
   откат, разбор падений и окно ошибки, отложенные операции с файлами, переводы. Её используют Legacy и 3.0. Связь с
   платформой — через небольшие точки подключения (журнал, папка игры, версия).
2. **Гибридное ядро** (внутри NeoForge 1.21.1):
   - поиск модов и определение вида: NeoForge (`META-INF/neoforge.mods.toml`), Forge (`META-INF/mods.toml`),
     Fabric (`fabric.mod.json`);
   - общий граф зависимостей на все три вида с соответствиями (`fabric-api` → Fabric API под NeoForge, `forge` →
     NeoForge и т. п.) и предпроверкой с понятным текстом;
   - слой Fabric: перевод мода на имена игры NeoForge (классы, миксины и их refmap, access widener → access transformer),
     кэш переведённых jar, Fabric Loader API (наш код из Legacy) и Fabric API под NeoForge;
   - слой Forge: перенаправление Forge API на аналоги NeoForge и переходники для несовпадающего;
   - безопасный запуск для всех трёх видов.
3. **Клиент Argentum под NeoForge**: каталог, окна, кнопка на экране ресурспаков. Логика — в Core, экраны переписываются под
   имена игры NeoForge.
4. **Установщик**: выбор «Argentum Legacy / Argentum 3.0»; для 3.0 ставит NeoForge нужной версии и компонент Argentum.

Проверить по ходу (не на память): как NeoForge 1.21.1 даёт встроиться в поиск модов (точки расширения FML); под какими
именами классов работает Forge 1.21.1 во время игры.

## Запуск игры (этап 1)

1. Лаунчер запускает NeoForge, NeoForge подхватывает ядро Argentum.
2. Ядро находит моды, определяет вид, переводит новые Fabric- и Forge-моды (готовые — из кэша), строит общий граф.
3. Предпроверка: если набор не запустится — понятное окно до загрузки игры.
4. NeoForge грузит свои моды, ядро — Fabric- и Forge-моды через свои слои; все в одной игре.
5. Главное меню: снимок рабочего набора.

## Ошибки

- Мод, который не удалось перевести, не ломает запуск: он отключается, в окне — почему.
- Защита от цикла падений, окно ошибки, откат — для всех трёх видов.
- В отчёте указан вид мода (Fabric / Forge / NeoForge) и слой, на котором сломалось.

## Проверка

- Автотесты: перевод имён, определение вида мода, общий граф зависимостей.
- Контрольный набор в отдельном инстансе Prism — собирается и проверяется в каждой большой итерации.

## Порядок работы

1. Этот документ и вынос **Argentum Core** из нынешнего кода (Legacy работает как раньше).
2. Заготовка ядра под NeoForge 1.21.1: загружается внутри NeoForge и находит моды всех видов.
3. Слой Fabric (сначала простые моды, затем тяжёлые), затем слой Forge.
4. Клиент Argentum под NeoForge, затем установщик с выбором редакции.

Оценка до рубежа 1: порядка 15–25 рабочих сессий; больше всего неизвестного — в тяжёлых Fabric-модах.
